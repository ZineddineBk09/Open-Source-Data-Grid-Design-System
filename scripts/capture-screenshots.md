# Screenshot guide

Screenshots live in **`apps/demo/public/screenshots/`** (served by Vite and copied to GitHub Pages).

| File | Story / scene |
|------|----------------|
| `grid-light.png` | Light mode, sorted column |
| `grid-dark.png` | Dark mode, row selected |
| `column-filters.png` | Active column filters |
| `virtual-scroll.png` | VirtualScrollStressTest, scrolled |
| `pinned-column.png` | PinnedColumns story |
| `expandable-hierarchy.png` | TreeData story |

Capture with **Cmd+Shift+4 → Space → click window** on macOS.

After replacing images, paths in `apps/demo/src/main.tsx` and `README.md` should stay as `.png` under `public/screenshots/`.
