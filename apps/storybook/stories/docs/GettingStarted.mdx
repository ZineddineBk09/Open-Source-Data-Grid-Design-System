# Open-Source Data Grid Design System

A headless, high-performance data grid for **React** and **Vue** — built for enterprise applications handling large datasets.

**Live demo:** [GitHub Pages](https://zineddinebk.github.io/Open-Source-Data-Grid-Design-System/) · **Source:** [GitHub](https://github.com/ZineddineBk09/Open-Source-Data-Grid-Design-System)

## Features

- **Virtual scrolling** — smoothly render 100k+ rows
- **Column filters** — per-column operators (contains, equals, gt/lt) + global search
- **Sorting & grouping** — multi-column sort, expandable group rows
- **Tree data** — nested expandable rows via `getSubRows`
- **Column pinning** — sticky left/right columns with edge shadows
- **Row selection** — single/multi select with shift-click range
- **Inline editing** — double-click to edit; undo/redo (Ctrl+Z)
- **Server-side mode** — manual pagination/sort/filter with loading states
- **CSV export** — export selected or all rows
- **Keyboard navigation** — arrow keys, space, enter, escape
- **Accessibility** — ARIA grid roles, sort indicators, focus management
- **Theming** — Tailwind CSS preset, density variants, dark mode, custom `theme` prop

## Architecture

```
@zineddinebk/grid-core              Headless engine (Zustand store, pipeline, utils)
@zineddinebk/grid-react             React DataGrid component + hooks
@zineddinebk/grid-vue               Vue DataGrid component + composables
@zineddinebk/grid-tailwind-preset   Design tokens and utility classes
```

## Quick Start (React)

```tsx
import { DataGrid } from '@zineddinebk/grid-react';
import '@zineddinebk/grid-react/styles.css';

<DataGrid
  data={employees}
  columns={columns}
  getRowId={(row) => row.id}
  enableRowSelection
  enableGlobalFilter
  showColumnFilters
  height={500}
  onCellEdit={(rowId, columnId, value) => updateCell(rowId, columnId, value)}
/>
```

## Quick Start (Vue)

```vue
<script setup>
import { DataGrid } from '@zineddinebk/grid-vue';
import '@zineddinebk/grid-vue/styles.css';
</script>

<template>
  <DataGrid
    :data="employees"
    :columns="columns"
    :get-row-id="(row) => row.id"
    :show-column-filters="true"
    :height="500"
    @cell-edit="handleCellEdit"
  />
</template>
```
